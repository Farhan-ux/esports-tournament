# E-sports Tournament Dashboard

Live tournament tracking for the Nexus Arena Championship 2024, built with Next.js 14 and Recharts.

## Features

- **8-Team Standings** — Sorted by wins with round differential
- **Tournament Bracket** — 7-match bracket from quarterfinals to grand final with MVPs
- **Live Match Panel** — Team comparison with per-role rating bar chart
- **Player Leaderboard** — Top 10 by HLTV rating with K/D/A, ADR, and HS%
- **Match Feed** — Real-time event stream with kill highlights and system events

## Tech Stack

- Next.js 14 (Pages Router)
- TypeScript
- Tailwind CSS
- Recharts

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
